## Telegram

В журнале есть `message can't be deleted for everyone`. Старый код сообщал
об успехе после ошибки. Новая очистка пропускает одиночные неудаляемые сообщения,
обрабатывает не более 500 ID, сохраняет закреп без unpin/repin и не сбрасывает
ожидающие permissions/questions. Частичная очистка и сетевая ошибка обозначаются
явно. Возрастное ограничение Telegram остаётся; число проверенных ID не равно
числу реально удалённых сообщений. Реальный чат в тестах не удалялся.

## Vyce AI

`Set-BeeVyceProvider.ps1 -KeyFile <file>` добавляет отдельный provider и позволяет
заменять ключ. Ключ хранится вне Git в OpenCode secrets с ACL текущего пользователя
и SYSTEM; config содержит file-reference. Это plaintext-файл, не зашифрованное
хранилище. Исходный файл пользователя автоматически не удаляется.

API /models доступен; короткий chat/completions запрос к deepseek-v4-flash успешен.
Названия и context взяты из ответа сервиса; подлинность backend-моделей независимо
не проверена. Output установлен консервативно 4096, неизвестный LR context — 32768.
Image-only модель не добавлена в coding-модели. Tool calling/vision всех моделей
не проверены. Назначения моделей агентам и локальный default не изменены.

Приоритет дальнейшей проверки: ручное нажатие очистки, перезапуск OpenCode,
выбор Vyce через /models и безопасная пробная задача. Для работы специалистов
через Vyce нужно отдельно выбрать их модели в AI-команде BeeForge.
