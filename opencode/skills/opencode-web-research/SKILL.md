# Web research

Use `websearch` to discover sources and `webfetch` to read the most relevant pages. When repository history, releases, issues, pull requests, Actions, or code are relevant and GitHub MCP is assigned, search GitHub directly as well.

Prefer primary and authoritative sources. For claims about a person, organization, achievement, date, or identity, corroborate with at least two independent sources when practical. Distinguish confirmed facts, conflicts, reasonable inferences, and information that could not be found.

Return source URLs next to the claims they support. Record useful image-page URLs separately from direct image URLs, and state the usage or licensing status when known. Do not infer identity from an image alone, bypass access controls, collect sensitive personal data, or present namesakes as the target person.

For developer libraries and APIs, use the `find-docs` skill instead of general web search when it is available. Never include secrets, private source text, credentials, or personal data in search queries.
